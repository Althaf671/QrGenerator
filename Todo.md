# QR Code Generator dengan ASP.NET Core

Kita akan membuat program-program untuk mengubah sebuah link menjadi kode QR dengan menggunakan ASP.NET Razor Pages 

## Goals
- Inputkan URL random
- Aplikasi validasi URL
- Aplikasi membuat QR dari URL
- QR Code ditampilkan di halaman
- Tombol unduh QR jadi PNG

## Libraries & Framework
- ASP.NET Razor Pages
- QRCoder
- Boostrap 5

## Konsep atau Implementasi yang dipakai
- Simple Razor Pages
- Data annotations
- Dependency Injection
- Service Abstraction
- File response
- Data URI
